## Inspiration
During the COVID-19 pandemic, I had nothing to do during the lockdown. I liked playing around in Roblox Studio,
so I decided to try something different, and I tried to make a Discord bot  for my Discord server. It was originally
intended for just me and my friends, but I really enjoyed working on it, which led me to keep adding more features.


## Overview and History
Alpine is a multipurpose Discord bot that serves 100,000+ users, and is in 90+ servers.

This project was my first major project using Python, which I still work on today.
I originally started this project using JavaScript with discord.js, but at the time, I thought it was too hard.
So I tried Lua, but I really didn't like it. Then I switched to Python. The code of Alpine in JavaScript and Lua
is long gone, so don't ask for it.

Alpine first started with the name "avibot" for a short time, and the name "Avimetry" was decided, the name comes from a
combination of avizum and symmetry. I wasn't too attached to that name, so around October of 2023, the current name
"Alpine" was chosen.

## Features
Alpine is feature rich with over 150 commands. Listing them all will be a bit much, so the Modules along
with their description will be listed:

| Module            | Description                                                                                                                                                             |
|-------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Bot Info          | Utility and informational commands covering the bot itself: uptime, ping, invite links, changelog/commits, vote links, and support server access.                       |
| Fun               | Lighthearted, joke-oriented commands like 8ball, roast, ship, dropkick, and text-to-speech — the kind of commands meant purely for entertainment in a server.           |
| Games             | Interactive mini-games playable directly in Discord, including Akinator, rock-paper-scissors, a cookie-clicking game, and logo-guessing/reaction-speed challenges.      |
| Highlight         | Keyword-tracking system that notifies you when a word or phrase you've registered is mentioned, with commands to add, remove, block specific users, or clear your list. |
| Images            | A large selections of image manipulation and meme-generation commands                                                                                                   |
| Meta              | General purpose utility commands, like polls, user, role, and server lookup, user avatar and banners, time zones, etc.                                                  |
| Moderation        | Server moderation tools.                                                                                                                                                |
| Music             | Voice channel music playback using Lavalink, with button controls. Also has a queue system.                                                                             |
| Server Management | Server configuration commands for creating and deleting channels or categories, cloning channels, creating roles, and "borrowing" custom emojis from other servers.     |
| Settings          | Bot and server configuration commands.                                                                                                                                  |
