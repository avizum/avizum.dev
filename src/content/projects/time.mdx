## Overview
Time zones can be hard. So I made this bot for one of my friends. It helps you tell time in different time zones.

## Features
- Default time zone: set your primary time zone, this is shown first whenever you check the time using the `/times` command, and will be used to show the time difference with other time zones you're following
- Follow time zones: add up to 20 additional time zones to track alongside your defualt time zone
- Custom UTC (GMT) offsets: Allows for unusual time zone offsets, like UTC-08:27.
- `/times`: displays the current time with the default zone first, then the time zones that you're following, in the order you added them, in one message.
- Per-user: time zones are tied to Discord users, not Discord servers, so they follow you to any server.
- User installable: install the bot to your user, and use it anywhere in Discord.

## Summary
Time is a utility bot that helps with time zones. It converts your default time zone to a list of other time zones that you specify.
